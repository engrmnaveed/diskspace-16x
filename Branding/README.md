# Space 16X identity

Space 16X is the display name. Use `space16x` for the command and 16X Brains for the company credit.

The app icon depicts a disk with three sections of different sizes. The wider aqua section identifies the largest share. The same mark appears in the project lockup.

| Role | Color |
| --- | --- |
| Navy | `#102238` |
| Aqua on dark surfaces | `#4DF2CF` |
| Teal on light surfaces | `#086958` |
| Light text on navy | `#F2F8FF` |

The app uses the macOS system typeface and semantic text and background colors. Product labels distinguish views and states in addition to color.

Run `swift Branding/generate.swift` on macOS to regenerate `AppIcon.icns` and `Lockup.png`. The icon contains native 1× and 2× renditions for Finder, the Dock, and the system app switcher. The PNG is the project lockup for documentation.
